## Prompt structure

For a portrait of a fictional adult, write a plain description first, then the photographic terms. Keep the same description across shots so the character stays consistent, and change only the framing words: head and shoulders for a portrait, full figure visible for a full-length shot.

Models with two text encoders can take two versions of the same idea: short comma-separated tags for CLIP and one descriptive sentence for T5.

## Words and phrasing that work

*   **Portrait:** name an 85mm lens, shallow depth of field and soft natural lighting.
*   **Full length:** name a 50mm lens and a balanced full-length composition.
*   **Detail:** natural skin texture and sharp focus do more than stacked quality words.
*   **Phone shots:** say where the phone is and how the camera angle follows from it, for example held above with the subject looking up.
